# Documentação das APIs — Vortexor

Esta seção documenta detalhadamente os principais domínios de API do ecossistema Vortexor, cobrindo autenticação, clubes, gamificação, pagamentos, staking, comentários, atividades, integrações externas e muito mais.

- [autentic/](./autentic.md): Autenticação, perfis, conexões e segurança.
- [video/](./video.md): Upload, streaming, manipulação e controle de vídeos.
- [club/](./club.md): Gestão de clubes, perfis, rankings, prêmios, conexões e integrações.
- [rental/](./rental.md): Aluguel de ativos, contratos e histórico.
- [admin/](./admin.md): Painel administrativo, auditoria, estatísticas, gerenciamento de usuários e conteúdo.
- [battlepass/](./battlepass.md): Sistema de battlepass, missões, recompensas e seasons.
- [level/](./level.md): Níveis, XP, progressão e analytics.
- [staking/](./staking.md): Staking de ativos, delegação, recompensas.
- [comment/](./comment.md): Comentários, moderação, notificações.
- [activity/](./activity.md): Atividades, eventos, gamificação.
- [trivo/](./trivo.md): Operações de mercado, cases, trading, upgrades.
- [stripe/](./stripe.md): Pagamentos, webhooks, checkout, produtos.
- [auth/](./auth.md): Fluxos de autenticação, tokens, permissões.
- [ads/](./ads.md): Anúncios, campanhas, eventos.

Cada módulo contém diagramas Mermaid, exemplos de payloads, respostas, tabelas de taxas/limites, explicações de segurança e compliance.
