Esta seção documenta detalhadamente os módulos de conta, sessão, perfil, chaves, análise e integrações externas do ecossistema Vortexor.

- [application/](./application.md): Serviços de conta, informações, conexões, assinatura, registro e elementos de perfil.
- [accounts/](./accounts.md): Sessão, visão, geração de chaves, análise de usuário e status.
- [references/](./references.md): Integrações externas (Steam, Stripe, Tebex).
- [clubr/](./clubr.md): Recursos sociais, gamificação, monetização, níveis e estúdio de clubes.

Cada módulo pode conter diagramas Mermaid profissionais para ilustrar fluxos e arquitetura, além de seções de custos, taxas, pontos e notas de segurança/compliance.
